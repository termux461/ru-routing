01 / Категории

Что открывать напрямую?

Можно выбрать несколько категорий сразу.

Категории содержат отдельные найденные IP доменов. Полные подсети компаний доступны в общем файле репозитория.

Каталог загружается из публичного репозитория и обновляется каждый час. Можно также скачать tunneling-list.json на GitHub и загрузите сюда. Данные обрабатываются в браузере.

03 / Подключение

Как использовать

01 · Выберите списокОтметьте нужные категории и формат вашего клиента.
02 · Импортируйте файлВ Amnezia отключите VPN, выберите режим «сайты из списка не должны открываться через VPN» и импортируйте JSON.
03 · Проверьте соединениеПроверьте свой IP на нужном сервисе. После обновления списка импортируйте его повторно.
RU Routing · При прямом подключении сервисы видят ваш обычный IP. Совместное использование IP может затронуть другие сайты.
