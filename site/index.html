Можно выбрать несколько сервисов из разных групп. По умолчанию выбран Telegram.

Формат

Подсети могут включать общие CDN и другие сайты. Большой список маршрутов может не подойти телефону. Это все допустимые публичные IPv4 и подсети, которые вернул источник при последнем обновлении, а не гарантия всех адресов сервиса. Частные и служебные диапазоны исключены.

Добавить свой файл

Можно добавить адреса и домены с IP из своего Amnezia JSON к выбранным сервисам. Файл обрабатывается в браузере.

Другие форматы и IPv6 через IPList

Выберите один портал или всю группу. Файл формирует внешний IPList; запрос откроется на его сайте.

Не все форматы работают со всеми типами данных. IPv6 и отдельные файлы IPList могут не поддерживаться вашей версией Amnezia. Скрипты стороннего сервиса могут удалять записи или менять маршруты — проверяйте их перед запуском.

Как подключить

  1. Выберите сервисы, проверьте размер и скачайте Amnezia JSON.
  2. Отключите VPN в Amnezia, включите раздельное туннелирование сайтов и выберите «Сайты из списка должны открываться через VPN».
  3. Импортируйте JSON. «Заменить список» удалит прежние записи этого режима. Подключите VPN и проверьте нужные приложения.
  4. После обновления данных скачайте файл и импортируйте его повторно: Amnezia не обновляет импорт автоматически.

Если что-то не работает, напишите в issues.

Для Telegram добавлены официальные IPv4-подсети. Сервис может использовать меняющиеся адреса, общие CDN и IPv6, поэтому полная работа всех приложений не гарантируется. Остальной трафик при выбранном режиме идёт напрямую и видит ваш обычный IP.
