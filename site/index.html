Загрузить свой список

Можно загрузить готовый список текущего режима или выбрать свой JSON-файл. Обрабатываются только известные правила текущего каталога; полные подсети российского списка при этом не сохраняются. Файл остаётся в браузере.

Больше сервисов и форматов — IPList

Выберите портал или целую группу. Файл формирует внешний сервис IPList; выбранные параметры отправляются ему напрямую.

Данные IPList могут содержать общие IP и очень широкие подсети. Они могут затронуть другие сервисы или быть слишком большими для телефона. Скрипты MikroTik и BAT могут менять маршруты или удалять записи — проверьте содержимое перед запуском. Amnezia-файлы IPList могут содержать пустое поле IP; совместимость зависит от версии клиента.

Готовые списки российских сервисов

Внешние файлы amnezia-tunneling-ru предназначены для режима «адреса из списка не должны открываться через VPN»:

  • IP-список Lite — меньше подсетей.
  • Полный IP-список — очень много маршрутов, может не подойти телефону.
  • Список доменов — некоторые клиенты не определяют IP при импорте.

Это отдельные файлы стороннего проекта. Их данные и совместимость мы не проверяем при каждой сборке; отдельные общие IP могут затронуть другие сайты.

Как подключить

  1. Выберите категории и формат вашего клиента, затем скачайте файл.
  2. В Amnezia отключите VPN, включите раздельное туннелирование сайтов, выберите режим «сайты из списка должны открываться через VPN» и импортируйте JSON.
  3. Подключите VPN и проверьте свой IP на нужном сервисе. Выберите «Заменить список», чтобы удалить прежние правила этого режима. После обновления файла импортируйте его повторно.

Если нужный сервис не открывается, напишите в issues.

При прямом подключении сервисы видят ваш обычный IP. Один IP могут использовать несколько сайтов, поэтому правило может затронуть и другие сайты. Для YouTube и других CDN часть адресов меняется динамически; список не гарантирует работу всех приложений и IPv6.
