# Настройка клиентов: выбранные сервисы через VPN

Готовые файлы маршрутизируют выбранные сервисы через VPN, когда правило направлено на VPN-подключение. Они не создают само VPN-соединение. Адреса и состав списка обновляются; приложения и CDN могут использовать дополнительные адреса.

## Amnezia VPN

Скачайте [vpn-list.json](dist/vpn-list.json) для всех сервисов или соберите файл с нужными сервисами на [странице проекта](https://termux461.github.io/ru-routing/). Отключите VPN, включите раздельное туннелирование сайтов и выберите **«Сайты из списка должны открываться через VPN»**. Импортируйте файл с заменой списка этого режима, затем подключите VPN. Замена удаляет старые пользовательские записи режима; сохраните их заранее, если они нужны.

Telegram включён вместе с официальными IPv4-подсетями. Проверьте подключение в самом приложении и в браузере; поддержка раздельного туннелирования зависит от платформы, версии и профиля клиента. Обновление файла в GitHub не обновляет его в Amnezia: повторно импортируйте новый файл.

## sing-box 1.11+

Скопируйте `dist/vpn-sing-box.json` как `vpn-sites.json` рядом с конфигурацией. Добавьте источник и правило в существующий объект `route`:

```json
{
  "rule_set": [
    { "tag": "vpn-sites", "type": "local", "format": "source", "path": "./vpn-sites.json" }
  ],
  "rules": [
    { "rule_set": "vpn-sites", "action": "route", "outbound": "proxy" }
  ],
  "final": "direct"
}
```

`proxy` — пример тега вашего настроенного VPN outbound, `direct` — тег прямого outbound; оба должны существовать в конфигурации. Объедините пример со своими правилами и проверьте `sing-box check -c config.json`. Если другие правила или DNS меняют маршруты, итог может отличаться.

## Clash / Mihomo

Скопируйте `dist/vpn-clash.yaml` в `vpn-sites.yaml` и объедините с конфигурацией:

```yaml
rule-providers:
  vpn-sites:
    type: file
    behavior: classical
    path: ./vpn-sites.yaml
rules:
  - RULE-SET,vpn-sites,VPN
  - MATCH,DIRECT
```

`VPN` — пример имени вашей существующей группы или прокси; замените на фактическое. Учитывайте порядок остальных правил. Проверьте конфигурацию `mihomo -t -f config.yaml` для своей версии клиента.

## Ограничения

Списки основаны на IPv4 доменов и официальных IPv4-подсетях Telegram. Amnezia и другие клиенты по-разному обрабатывают домены, DNS и IPv6. У YouTube и других CDN IP могут меняться и разделяться между разными сервисами: часть нужного трафика может пойти напрямую, а другие сайты на том же IP — через VPN. Проверьте нужные сервисы и IP на своём устройстве. Старый `dist/tunneling-list.json` предназначен для противоположного режима и в этот режим не подходит.
