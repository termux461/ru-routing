# Клиенты и форматы

Списки управляют маршрутизацией в вашем VPN-клиенте и не создают VPN-соединение. Настройте VPN и проверьте работу каждого используемого устройства.

## Amnezia VPN

Скачайте `dist/tunneling-list.json` для полного набора сетей или `dist/category-<категория>-amnezia.json` для отдельной категории. Отключите VPN, включите раздельное туннелирование сайтов и выберите «Адреса из списка не должны открываться через VPN», затем импортируйте JSON. При замене предыдущие исключения удаляются; выберите добавление, если хотите их сохранить. При обновлении файла на GitHub повторите импорт вручную. Разные версии клиента и протоколы могут по-разному поддерживать IPv4-маршруты: проверьте IP на конкретных сайтах.

## sing-box 1.11+

Используйте `dist/sing-box.json` или `dist/category-<категория>-sing-box.json` как локальный source rule-set. Добавьте в существующие секции `route.rule_set` и `route.rules`:

```json
{"rule_set":[{"tag":"ru-services","type":"local","format":"source","path":"./ru-services.json"}],"rules":[{"rule_set":"ru-services","action":"route","outbound":"direct"}]}
```

Скопируйте файл как `ru-services.json`; outbound с тегом `direct` должен существовать. Правило разместите перед общим правилом маршрутизации через VPN. Это фрагмент, не полная конфигурация. Проверьте конфигурацию своей версией `sing-box check -c config.json`.

## Clash / Mihomo

Скопируйте `dist/clash.yaml` или файл категории в `ru-services.yaml`. Добавьте в существующую конфигурацию:

```yaml
rule-providers:
  ru-services:
    type: file
    behavior: classical
    path: ./ru-services.yaml
rules:
  - RULE-SET,ru-services,DIRECT
  # далее остальные правила и ваша VPN-группа
```

Проверьте конфигурацию командой `mihomo -t -f config.yaml` для вашей версии клиента. При удалённой подписке приватный GitHub-репозиторий требует авторизации; не вставляйте секретные токены в публичные конфигурации.

## Как различаются правила

Категории содержат точечные IPv4 доменов, а полный файл дополнительно включает выбранные подсети компаний. В sing-box и Clash доменные правила являются суффиксными: они включают поддомены и могут направлять сервис напрямую даже при смене CDN. Правильное сопоставление зависит от DNS и настроек клиента. Файлы генерируются для IPv4; поведение IPv6 устанавливается отдельно. Общий IP может использоваться несколькими сайтами. Автоматическая генерация и проверка формата не заменяют теста на устройстве.
