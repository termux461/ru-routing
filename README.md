# Сервисы через VPN

[Открыть страницу](https://termux461.github.io/ru-routing/) · [Сообщить о проблеме](https://github.com/termux461/ru-routing/issues)

Страница собирает список адресов **выбранных** сервисов для раздельного туннелирования. Выбирайте отдельные сервисы из разных групп, проверяйте размер и скачивайте файл. В Amnezia выберите режим, в котором сайты из списка открываются через VPN. Режима со списком российских сервисов на странице больше нет.

Доступны Amnezia JSON, sing-box JSON (source rule-set), Clash/Mihomo YAML, IPv4 txt, JSON и CSV, MikroTik address-list и ipset restore. Можно добавить адреса из собственного Amnezia JSON. Для других форматов и IPv6 есть отдельный запрос к IPList — он формирует файл на своём сайте.

## Источники и ограничения

Каждый час GitHub Actions запрашивает у [IPList](https://iplist.opencck.org/ru/) найденные для каждого портала отдельные IPv4, IPv4-подсети и домены. Отдельный IP, уже входящий в подсеть, не повторяется; остальные сохраняются. Частные, служебные и некорректные адреса исключаются. Для Telegram дополнительно добавляются все опубликованные [официальные IPv4-подсети](https://core.telegram.org/resources/cidr.txt). Если источник недоступен, существующая опубликованная версия сохраняется; сервисы с неполными данными становятся недоступны для выбора.

Это все допустимые публичные IPv4 и подсети из указанных источников, но **не гарантия всех существующих адресов**: адреса меняются, зависят от региона, а IPList может содержать не все сети. IPv6 через страницу формируется только отдельным запросом к IPList. Некоторые сети принадлежат общим CDN или очень широки, поэтому через VPN могут пойти и другие сайты. Проверьте размер и примеры широких подсетей перед импортом; большие списки могут не работать на некоторых устройствах. Маршрутизация зависит от настроек и возможностей конкретного VPN-клиента.

Обновление файлов в репозитории не меняет уже импортированный список в Amnezia: новый файл нужно скачать и импортировать вручную. Если выбрать «заменить список», текущие записи соответствующего режима будут удалены. Остальной трафик в режиме сайтов через VPN идёт напрямую и использует обычный IP.

Проект использует данные IPList; лицензия источника находится в [THIRD_PARTY_IPLIST_LICENSE.txt](THIRD_PARTY_IPLIST_LICENSE.txt). Ранее созданные данные российских маршрутов сохранены в истории и репозитории, их автоматическое обновление отключено.

## Разработка

Сайт — статический `site/index.html`, его можно разместить на GitHub Pages. PHP-скрипт `bin/build-full-vpn.php` формирует данные `dist/full-*.json` из IPList и официального списка Telegram. Для запуска нужны PHP с расширением curl и доступ к источникам. Проверка преобразований: `php tests/full-vpn.php`.
